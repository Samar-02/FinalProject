# SpaceX Falcon 9 Landing Prediction

A data science capstone completed as part of IBM Data Science coursework. This repository contains the notebooks used across the capstone workflow, from data collection and wrangling through exploratory analysis, visualization, dashboarding, and machine-learning prediction.

> **Portfolio note:** This was a guided course capstone rather than an independent research project. I am keeping it public to document the tools and workflow I practiced during the IBM Data Science program.

## Project objective

The capstone explores whether the first stage of a SpaceX Falcon 9 launch will land successfully. The workflow combines historical launch data, exploratory analysis, interactive visualizations, and classification models.

## Repository contents

- `Data Collection APi.ipynb` — collects launch data through an API
- `Data Collection Webscraping.ipynb` — gathers supplementary launch information through web scraping
- `Data Wrangling.ipynb` — cleans and prepares the data for analysis
- `EDA with SQL.ipynb` — explores the data using SQL
- `EDA with Visualization.ipynb` — visual exploratory analysis
- `Interactive Visual Analytics with Folium.ipynb` — geospatial exploration using Folium
- `Dashboard with Plotly Dash` — interactive dashboard work
- `Machine Learning Prediction.ipynb` — compares classification approaches for landing prediction

## Machine-learning methods

The machine-learning notebook works with classification methods including:

- logistic regression
- support vector machines
- decision trees
- k-nearest neighbors

Hyperparameter tuning and test-set evaluation are used to compare model performance.
